# server/docs — topic index

package [README.md](../README.md) (the overview). Referenced from
`CLAUDE.md`'s "Further reading" section as a conditional link, so it loads
only when a task actually touches the topic — not on every session.

One file per topic, named after the topic (`repo-intel-ranking.md`,
`review-run-executor.md`, …). Empty for now — add a file here when a piece of
server behavior needs more explanation than a map entry, and link it from the
relevant module's `CLAUDE.md`.
