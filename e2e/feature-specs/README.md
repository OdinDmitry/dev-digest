# e2e/feature-specs — design specs

Design specs for planned/in-progress features — the "why/what we decided",
written before or alongside implementation. Named `feature-specs/`, not
`specs/`, because `specs/` is already taken by the flow JSON files
(`specs/NN-name.flow.json`) that drive the actual test runs — see
[CLAUDE.md](../CLAUDE.md).

Once a feature ships, fold anything still true into `CLAUDE.md` or
[docs/](../docs/) and either archive or delete the spec. One file per feature
(`0001-export-to-ci-flows.md`, …). Empty for now.
